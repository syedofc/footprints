    Repositories

    Git repositories on this device, when they were cloned and last used, and the AI agent files in them. Reads git metadata and file names, never your code, commit messages or author details. Agent files are read only to compute a fingerprint; their text is never stored or shown. Each scan is saved on this device to show what changed.

    Start the local app with python serve.py to scan repositories.

    Local results can include repository names, paths, and remote hosts. Use the simulated sample for screenshots and reports.

      Passports

      Forkit Core passports give an AI tool, an agent setup or a model a permanent, checkable identity. Every passport is checked: is the stored record unchanged, and is the same program or agent setup still there?

      Start the local app with python serve.py to create and check passports with Forkit Core.
